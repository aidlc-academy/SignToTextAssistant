# Basic Sign-to-Text Communication Assistant

A beginner-friendly Python project that uses your webcam to recognize
hand gestures and display the corresponding text on screen.

## What it does
- Captures hand gestures via webcam
- Detects hand landmarks using MediaPipe
- Recognizes 5–10 predefined gestures
- Displays matching text on screen
- Optional: speaks the recognized gesture aloud

> Note: This is a limited-gesture demo, not a full sign-language translator.

## Requirements
- Python 3.9 or higher
- A working webcam

## Setup (coming in later steps)
1. Install dependencies: `pip install -r requirements.txt`
2. Run the app: `python main.py`
